How to use Bionic Page

Install it once, then read any page normally. It takes about a minute to set up and one click to turn on or off.

1. Install

Pick your browser, or run it from source.

Chrome or Edge

Open the Chrome Web Store listing and choose “Add to Chrome”, then pin the toolbar icon.

Add to Chrome

Firefox

Open the Firefox Add-ons listing and choose “Add to Firefox”, then pin it to the toolbar.

Add to Firefox

From source

  1. bun install && bun run build
  2. Chrome: chrome://extensions → Developer mode → Load unpacked → dist/chrome
  3. Firefox: about:debugging → This Firefox → Load Temporary Add-on → dist/firefox/manifest.json

2. Use it

Open the popup

Click the Bionic Page icon in the toolbar. The popup shows the master switch, the mode, an intensity slider, and a “This site” switch for the page you are on.

If the status line says “Not available on this page”, the page has no readable DOM text (a PDF viewer or a canvas app), which is expected.

Pick a mode and intensity

Choose how the leading part of each word is emphasized. Start with Half, then try Classic and move the intensity slider if you want more or less emphasis.

Low distraction bolds the prefix and fades the rest, which some readers prefer on busy pages.

The page transforms

The text is rewritten in place. Code blocks, form fields, editors, and math are left alone, and turning it off restores the original text exactly.

Toggle per site

Use the “This site” switch, or add a match pattern in options, to keep a site on or off.

Keyboard shortcut

Press Ctrl Shift Y (or ⌘ Shift Y) to toggle on the current page.

Floating control

The small “Bp” button in the corner toggles the page without opening the popup. Turn it off in options if you prefer.

Fine-tune in options

The options page holds every setting: emphasis weight, faded remainder opacity, letter spacing, minimum word length, custom vowel sets, dynamic-content handling, iframes, and per-site rules.

The live preview at the bottom of the options page shows the result as you change values, and you can export or import your settings as JSON.

3. The five modes

Each mode emphasizes a different part of the word.

Mode What it does Best for
HalfBold the first half of each word.A first try; the familiar default.
ClassicBold a share of each word; intensity controls how much.Dialing the effect up or down.
Vowel anchorBold up to the first vowel group.Non-English text and long words.
Low distractionBold the prefix, fade the rest of the word.Busy pages; less visual noise.
Custom rulePer-length counts plus a fraction, e.g. 0 1 1 2 0.4.Exact control; reproducing another tool.

4. Troubleshooting

A page looks wrong after turning it on.
Toggle it off, then add that site to the off-list in options. The transform is fully reversible, so a reload is not required.
Nothing happens on a page.
PDFs, canvas apps, and some chat editors keep their text outside the DOM, so there is nothing to rewrite. The extension skips editors and code on purpose.
It feels slower than I expected.
Try Low distraction or reduce intensity. Peer-reviewed results on bionic emphasis are mixed; the effect is individual.
New content is not styled.
Check “Process new content as it loads” in options. It is on by default and uses a MutationObserver.
I want it gone completely.
Turn the master switch off to disable it everywhere, or remove the extension. No data leaves your browser either way.
