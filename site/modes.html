Reference

Reading modes

Five modes decide which part of each word is emphasized. They all run through the same pure function, so the demo on the home page and the extension agree word for word.

At a glance

The five modes, what each emphasizes, and when it tends to help.
ModeEmphasizesBest for
HalfThe first half of each wordThe familiar default
ClassicA share of each word, set by intensityTuning the effect up or down
Vowel anchorUp to the first vowel groupNon-English text, long words
Low distractionPrefix bold, remainder fadedBusy pages
Custom rulePer-length counts plus a fractionExact control

Each mode

Half

Fixation anchors the eye at the start of each word.

Bolds the first half of each word, rounded up, and nothing shorter than two letters. This is the Bionic Reading default and the shipped default mode.

Classic

Fixation anchors the eye at the start of each word.

Bolds ceil(letters × intensity) characters, with a minimum of one. The intensity slider, from 0.2 to 0.9, only changes this mode and Low distraction.

Vowel anchor

Fixation anchors the eye at the start of each word.

Bolds up to and including the first vowel group, capped at half the word plus one. A custom vowel set can be supplied for other languages; empty uses the built-in set.

Low distraction

Fixation anchors the eye at the start of each word.

Bolds the prefix and fades the remainder to the configured opacity, 72% by default. The faded part is wrapped in a span and removed exactly on revert.

Custom rule

Fixation anchors the eye at the start of each word.

Emphasizes a fixed character count per word length, then a fraction for longer words, using the rule string below. It bypasses the minimum word length.

The custom rule string

The default rule is 0 1 1 2 0.4. It is parsed left to right: an optional sign, up to four whole numbers, then one decimal fraction. Invalid input falls back to this default without throwing.

Optional sign
A leading + or - controls common-word handling. + allows the small built-in common-word list to be emphasized; no sign, or -, leaves it out.
Four whole numbers
The emphasized character counts for words of length 1, 2, 3, and 4. In 0 1 1 2: a one-letter word is left alone, a two-letter word emphasizes one character, three letters emphasize one, and four letters emphasize two.
One fraction
Applies to words of five letters or more. 0.4 emphasizes ceil(0.4 × letters) characters, so a ten-letter word emphasizes four.
0 1 1 2 0.4

Intensity defaults to 0.5 and is clamped to 0.2–0.9. The minimum word length defaults to 3 and is clamped to 2–8; the Half and Custom rule modes ignore it because they set the count directly.
