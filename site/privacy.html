Policy

Privacy

bionic-page is a local reading aid. It runs entirely in your browser and does not operate a server.

What it collects

Nothing is transmitted. The extension makes no network requests, contains no analytics and no telemetry, and has no accounts or sign-in. There is no server and no network code in the extension.

What it stores

Only your own settings: the enable switch, the selected mode, intensity, minimum word length, appearance options, and any per-site rules you add. They are stored with your browser's extension storage, which may sync through your browser vendor's own account if you have sync enabled. They never pass through this project.

Why it asks for access to all sites

The extension has to read the text of the page you are on to emphasize it. The <all_urls> host permission is required because a reading aid is only useful if it works on the pages you choose. Page content is processed in memory and discarded when you leave the page; nothing is uploaded or saved.

Permissions in plain words

storage
Saves your reading settings in the browser's extension storage.
activeTab
Applies or removes the reading style on the tab you are interacting with.
<all_urls>
Reads and restyles page text locally. Text is processed in the page and discarded.

How to verify it

This is an open-source project, so the claims above are checkable in the source. The files worth reading:

  • src/shared/browser.ts is the only module that touches the extension API namespace.
  • src/shared/storage.ts reads and writes settings and nothing else.
  • src/content/content.ts applies and removes the transform; it never sends page text anywhere.
  • scripts/manifest.mjs is the single source of the permission list, storage, activeTab, and <all_urls>.
  • site/assets/core.js is the compiled fixation algorithm the demo on this site runs, built from src/core/.

There is no fetch, no remote code, and no fallback to a network call in any of them.

Revoking access

Turning the extension off, disabling it, or removing it stops all processing immediately. Removing the extension deletes its stored settings.

Contact

Questions or a bug? Open an issue on the project's repository, linked in the footer.
