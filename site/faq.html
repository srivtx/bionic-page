FAQ

Scope, honest limits, and the questions the repository already answers.

Questions

Is it free and open source?

Yes — MIT licensed. "Bionic Reading" is a trademark of Bionic Reading GmbH; this project is not affiliated with or endorsed by it.

Does it work on PDFs or canvas apps?

No. Those keep text outside the DOM, so there is nothing to transform. The popup says so when it detects no readable text.

Will it break websites?

It only rewrites text nodes and skips code, editors, forms, math, nav, and anything marked data-bionic="off". It is fully reversible.

Does it slow pages down?

It transforms once, then only new content. Measured at roughly 180k–230k words/second; see docs/PERFORMANCE.md.

Does it read my data?

No. There is no server and no network code in the extension.

Does it run inside iframes?

Yes. The content script is registered for all frames and the Run inside iframes option is on by default, so same-page frames are processed too. Turn it off in options to leave frames alone.

Does it work with web components and shadow DOM?

It recurses into open shadow roots, because a tree walker does not cross a shadow boundary. Closed shadow roots cannot be reached and are left alone.

Does it work in Chrome and Firefox?

Yes. One TypeScript source tree builds both targets with a generated per-engine manifest, so the two cannot drift apart.

Trademark

"Bionic Reading" is a trademark of Bionic Reading GmbH. bionic-page is an independent project and is not affiliated with or endorsed by Bionic Reading GmbH.

Honest limits

bionic-page offers configurable visual anchoring. It does not claim a speed-reading benefit, and peer-reviewed results on bionic emphasis are mixed, so judge it on your own reading. Text kept outside the DOM, such as a PDF viewer or a canvas app, cannot be transformed.
