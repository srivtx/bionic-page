Turn any web page into a bionic reading page.

The extension rewrites the readable text of the page you are on so the leading part of each word carries more weight, giving the eye a fixed anchor per word. This is configurable visual anchoring, not a speed-reading claim; peer-reviewed results on bionic emphasis are mixed.

Reading is a sequence of small jumps. The eye lands on a word, takes in enough to recognise it, then moves on.

When the leading letters carry more weight, the rest of the word is easier to infer, and the line keeps its rhythm.

    03 Five reading modes

    Each mode anchors a different part of the word

    The effect is individual, which is why there is more than one. Every sample is rendered live by the same algorithm the extension ships, so the demo here and the extension agree word for word.

    • hover

      Half

      Fixation anchors the eye at the start of each word.

      Bold the first half of each word, rounded up, and nothing shorter than two letters. The shipped default.

    • hover

      Classic

      Fixation anchors the eye at the start of each word.

      Bold a share of each word set by intensity. Intensity scales every mode, not just this one.

    • hover

      Vowel anchor

      Fixation anchors the eye at the start of each word.

      Bold up to the first vowel group, capped at half the word plus one. A custom vowel set can be supplied for other languages.

    • hover

      Low distraction

      Fixation anchors the eye at the start of each word.

      Bold the prefix and fade the remainder, 72% by default. The faded part is removed exactly on revert.

    • hover

      Custom rule

      Fixation anchors the eye at the start of each word.

      A fixed character count per word length, then a fraction for longer words, from the rule string 0 1 1 2 0.4.

    04 How it works

    One reversible pass, three moves

    No servers, no accounts, no permanent changes. The extension reads your page locally and puts every word back exactly as it found it.

    01

    Scan

    Walks the visible text nodes of the page, skipping scripts, inputs, code, and anything marked off-limits.

    02

    Anchor

    For every word, the chosen mode bolds its leading letters — a predictable fixation point your eye can land on.

    03

    Restore

    Toggle off and the original text nodes come back byte-for-byte. A test literally diffs the DOM before and after.

    05 Controls

    Three ways to switch it, one rulebook per site

    A shortcut for your hands, a popup for setup, a quiet pill on the page for instant tweaks — and per-site rules so long-form sites get anchoring while everything else stays untouched.

    Command it

    One keystroke toggles the current page. Everything else is a click away.

    Ctrl+ Shift+ Y
    • Shortcut — toggle the page under your cursor, no mouse needed. On a Mac it is Cmd + Shift + Y.
    • Popup — pick a mode, set intensity, and turn the current hostname on or off.
    • Floating control — a quiet pill on the page, in its own shadow root so page styles cannot reach it.

    Per-site rules

    On for the sites you read, off everywhere else. A bare hostname is normalised, and the last matching rule wins.

    W en.wikipedia.org half · 0.50
    D developer.mozilla.org classic · 0.40
    N news.ycombinator.com vowel
    G github.com off

    06 Safety

    Safe by construction

    The rewrite is a local pass over text nodes, gated so it cannot touch the parts of a page that must not change.

    What it never touches

    • script, style, code, and pre
    • Form fields, contenteditable, and math
    • SVG, navigation, buttons, and toolbar or menu roles
    • Anything marked data-bionic="off" or aria-hidden="true"

    It also skips URLs, email addresses, and long unbroken runs.

    What it does handle

    • Single-page apps and infinite scroll, through a MutationObserver
    • Text a framework replaces inside an existing paragraph
    • Text inside open shadow roots (web components), in every frame
    • Optional letter spacing after the emphasis, if you want more separation

    Turning it off restores the original text nodes exactly; a test compares innerHTML before and after.

    08 Privacy

    No network. No analytics. No accounts.

    bionic-page is a local reading aid. It runs entirely in your browser and does not operate a server. It makes no network requests, contains no analytics and no telemetry, and has no accounts or sign-in.

    What it stores. Only your own settings: the enable switch, the selected mode, intensity, minimum word length, appearance options, and any per-site rules you add. They are stored with your browser's extension storage, which may sync through your browser vendor's own account if you have sync enabled. They never pass through this project.

    Why it asks for access to all sites. The extension has to read the text of the page you are on to emphasize it. The <all_urls> host permission is required because a reading aid is only useful if it works on the pages you choose. Page content is processed in memory and discarded when you leave the page; nothing is uploaded or saved.

    Permissions in plain words. storage saves your reading settings in the browser's extension storage. activeTab applies or removes the reading style on the tab you are interacting with. <all_urls> reads and restyles page text locally — text is processed in the page and discarded.

    How to verify it. This is an open-source project, so the claims above are checkable in the source. src/shared/browser.ts is the only module that touches the extension API namespace. src/shared/storage.ts reads and writes settings and nothing else. src/content/content.ts applies and removes the transform and never sends page text anywhere. scripts/manifest.mjs is the single source of the permission list. There is no fetch, no remote code, and no fallback to a network call in any of them.

    Revoking access. Turning the extension off, disabling it, or removing it stops all processing immediately. Removing the extension deletes its stored settings.

    09 Install

    Build it from source

    Store listings are not published yet. Both targets build from one source tree, so the Chrome and Firefox builds cannot drift apart.

    terminal — bionic-page
    $git clone https://github.com/srivtx/bionic-page
    $cd bionic-page && bun install
    $bun run build
    #Chrome/Edge: chrome://extensions → Developer mode → Load unpacked → dist/chrome
    #Firefox: about:debugging → This Firefox → Load Temporary Add-on → dist/firefox/manifest.json

    Toggle the page you are on with Ctrl/Cmd + Shift + Y, the popup, or the floating control.

    Requires Chrome 116 or newer, or Firefox 140 or newer. Releases are on GitHub.
