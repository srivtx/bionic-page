Turn any web page into a bionic reading page. Turn any web page into a bionic reading page.

The extension rewrites the readable text of the page you are on so the leading part of each word carries more weight, giving the eye a fixed anchor per word. This is configurable visual anchoring, not a speed-reading claim; peer-reviewed results on bionic emphasis are mixed.

    Five reading modes

    Each mode decides a different part of the word to emphasize. The effect is individual, which is why there is more than one.

    • Classic

      Fixation anchors the eye at the start of each word.

      Bold a leading share of each word; intensity controls how much.

    • Half

      Fixation anchors the eye at the start of each word.

      Bold the first half of each word, the Bionic Reading default.

    • Vowel anchor

      Fixation anchors the eye at the start of each word.

      Bold up to the first vowel group; suited to many languages.

    • Low distraction

      Fixation anchors the eye at the start of each word.

      Bold the prefix and fade the rest of the word.

    • Custom rule

      Fixation anchors the eye at the start of each word.

      Per-length character counts plus a fraction for longer words.

    Safe by construction

    The rewrite is a local pass over text nodes. It is gated so it cannot touch the parts of a page that must not change.

    What it never touches

    • script, style, code, and pre
    • Form fields, contenteditable, and math
    • SVG, navigation, buttons, and toolbar or menu roles
    • Anything marked data-bionic="off" or aria-hidden="true"

    It also skips URLs, email addresses, and long unbroken runs.

    What it does handle

    • Single-page apps and infinite scroll, through a MutationObserver
    • Text a framework replaces inside an existing paragraph
    • Text inside open shadow roots (web components)

    Turning it off restores the original text nodes exactly; a test compares innerHTML before and after.

    Privacy

    bionic-page makes no network requests and has no analytics, accounts, or telemetry. Your settings are the only thing stored, and they stay in the browser's own storage. Because the rewrite runs on your machine, the extension requests host access to read page text locally; nothing is sent anywhere, and removing the extension removes the settings.

    Read the full privacy page, including why <all_urls> is required and which source files you can read to verify it.

    Build it from source

    Store listings are not published yet. Both targets build from one source tree.

    git clone https://github.com/srivtx/bionic-page
    cd bionic-page && bun install
    bun run build

    Chrome or Edge: chrome://extensions → enable Developer mode → Load unpacked → select dist/chrome. Firefox: about:debugging → This Firefox → Load Temporary Add-on → select dist/firefox/manifest.json.

    Toggle the page you are on with Ctrl/Cmd + Shift + Y, the popup, or the floating control.
