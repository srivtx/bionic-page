Get the extension

Chrome and Firefox extension

Turn any page into a bionic reading page.

The extension rewrites the readable text of the page you are on so the leading part of each word carries more weight, giving your eye a fixed anchor per word.

Bionic Page is configurable visual anchoring, not a speed-reading claim. Peer-reviewed results are mixed, so judge it on your own reading.

How it works

  1. 1

    Install the extension

    Add it from the Chrome Web Store or Firefox Add-ons, or load it from source.

  2. 2

    Open any article and click the icon

    The toolbar icon applies bionic reading to the readable text on the page.

  3. 3

    Pick a mode and intensity

    Choose one of five modes, then set how much of each word is emphasized.

  4. 4

    Toggle per site

    Press Ctrl/Cmd+Shift+Y from anywhere, or use the floating control in the corner of the page.

Five modes, one source

Each mode decides a different part of the word to emphasize. The effect is individual, which is why there is more than one.

Classic

Bold a leading share of each word; intensity controls how much.

Half

Bold the first half of each word, the Bionic Reading default.

Vowel anchor

Bold up to the first vowel group; suited to many languages.

Low distraction

Bold the prefix and fade the rest of the word.

Custom rule

Per-length character counts plus a fraction for longer words.

Privacy

Bionic Page makes no network requests and has no analytics, accounts, or telemetry. Your settings are the only thing stored, and they stay in the browser's own storage. Because the rewrite runs on your machine, the extension requests host access to read page text locally; nothing is sent anywhere. Removing the extension removes the data.

An honest note on the science

Bionic Page does not claim a speed-reading benefit. It offers configurable visual anchoring, and you should judge it on your own reading. Read the research notes.

FAQ

Is it free?

Yes. Bionic Page is open source under the MIT license.

Does it work on PDFs or canvas?

No. Text inside PDFs, canvas, and most specialized viewers is not in the page DOM, so it cannot be rewritten safely. It works on normal HTML text.

Will it break sites?

It skips scripts, code, editors, math, SVG, and anything marked data-bionic="off". Toggling off restores the original text nodes exactly.

Is it accessible?

Every control is a native, labelled element. Emphasis is visual only, Low distraction changes opacity instead of weight, and the master toggle turns everything off. Screen readers may still announce emphasized text, depending on the reader.

Does it slow pages down?

The rewrite is a local pass over text nodes. Dynamic pages are handled with a batched MutationObserver, so the cost stays small.

Does it work in Chrome and Firefox?

Yes. One TypeScript source tree builds both targets with a generated per-engine manifest.

Can I turn it off per site?

Yes. Per-site overrides are evaluated last match wins, and there is a master toggle on top of them.

Does it read my data?

No data leaves your machine. There are no network requests, no analytics, and no accounts.
