# Brand — Bionic Page

One identity across the landing site, the popup, the options page, and the
store listings. Tokens live in `site/styles.css` and are mirrored by the
`--bp-*` custom properties injected by the UI.

## Name

**Bionic Page** — two words, always capitalized. Never "BionicPage".
Short form / package id: `bionic-page`. The wordmark itself is bionic: the
leading letters of each word carry the weight.

```
Bi(on)ic  Pa(ge)      ← rendered:  <b>Bi</b>onic <b>Pa</b>ge
```

## Voice

Plain, calm, and honest. We never claim to make you read faster. We say what
the feature does, and we say when the science is mixed. No exclamation marks,
no hype verbs ("supercharge", "10x"), no emoji in product copy.

## Type

- UI / headings: system stack —
  `ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`.
- Reading demo (long paragraphs): `Georgia, "Iowan Old Style", serif` at
  `1.06rem`/`1.75`, max `68ch`.
- Emphasis weight: `700` default (`--bp-bold-weight`, user-configurable
  500–900). The emphasized head is ink; the tail is `--bp-mute` in `dim`
  mode, full body otherwise.

## Shape & motion

- Radius: `10px` controls, `16px` cards, `999px` pills.
- Borders: always `1px solid var(--bp-hairline)`. No shadows except one soft
  card shadow (`0 1px 2px rgb(20 22 26 / 6%)`).
- Focus: `outline: 2px solid var(--bp-accent); outline-offset: 2px`.
- Transitions: `140ms ease` on color/background/border only. No transforms on
  large surfaces, no gradients, no animation loops.

## Accessibility rules

- Body text ≥ `4.5:1` contrast on its background in both schemes.
- Every control is a native element with a `<label>` or `aria-label`.
- The wordmark has a text alternative: `aria-label="Bionic Page"`.
- Respect `prefers-reduced-motion` (transitions become instant).
- Min tap target `44×44px` on touch (`32px` allowed for the in-page control
  because it is not primary navigation, but it is keyboard focusable).
